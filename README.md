# HonorDuoX

[![版本](https://img.shields.io/github/v/release/rdcjed/honorduoX?label=version&color=blue)](https://github.com/rdcjed/honorduoX/releases/latest)

将荣耀 MagicOS 状态栏右侧的 **Wi-Fi、移动信号、电池** 合并为一个仿 iPhone「Duo」风格的三合一字形模块。

全层（宿主层 Hook、图形渲染引擎、状态采样与设置界面）统一采用 Kotlin 实现，应用包名 `io.github.rdcjed.honorduox`。

<img src="docs/images/statusbar.png" width="100%" alt="状态栏实拍：三合一字形接管 Wi-Fi、信号与电池">

## 核心特性

- **三合一字形**：支持圆环与胶囊双形态，宽度申报即时响应，邻近图标自动平滑让位。
- **智能防烧屏**：专为 OLED 屏幕设计的 30 秒 3×3 离散网格微米级平移机制，结合边界安全钳制，保护屏幕且功耗极低。
- **灵动胶囊智能避让**：胶囊展开时基于屏幕物理坐标执行单组件碰撞检测，仅避让受遮挡组件，并智能恢复可用空间内被原生误杀的状态栏图标。
- **灵活分区与候选**：上、中、下三个区域支持自由点选组件，具备有序候选回退能力。
- **丰富可放置组件**：电量数字、Wi-Fi 弧、移动信号（支持卡一卡二拆分）、网络类型、充电闪电、功率、温度、帧率、时钟等均可独立放置或交还系统。
- **信号堆叠（原信号样式）**：双卡信号上下排列，每张卡分别显示网络类型和圆头信号柱，首格为圆点；支持 4 格或 5 格，以及大小、粗细和间距调节。信号与 Wi-Fi、电池保持垂直对齐，关闭三合一图标时也可独立使用。流量箭头使用系统图标，显示在当前使用移动数据的 SIM 卡信号上。
- **网络类型样式**：关闭三合一后，独立网络标签和原信号样式堆叠均支持调整字号、字重及 5GA 中 A 的比例。
- **Wi‑Fi 图标样式与颜色**：圆润弧线、圆润回环和分层扇形支持三层或四层，可调整尺寸和线条粗细。颜色可选跟随系统、深蓝、绿色和粉色，绿色与电池充电色同步。
- **状态栏网速**：「硬件读数」可调整网速字号，并选择状态栏左顶、中部、右顶或恢复系统位置。网速由系统实时采样。
- **状态栏缩放与间距**：「基础外观」可将状态栏图标整体缩放至 50%～120%，并分别调整左侧和右侧间距。
- **状态栏高度**：「基础外观」可在系统高度基础上调整 −8 到 +16 dp，0 dp 跟随系统。降低时保留开孔和图标所需空间。
- **独立电池图标**：关闭三合一图标后，可调整电池图标大小（50%～130%）并切换竖向样式。电池、Wi‑Fi 和移动信号各自有显示开关。
- **环外读数自适应堆叠**：移动信号支持移至环外，提供**圆点副卡**与**双排柱**两种样式，支持 **4 信号柱与 5 信号柱**自由切换及全维度比例自适应；功率、温度、电流、电压、帧率支持**顺序感知自适应堆叠**，按开启顺序智能拆分与两两堆叠，严格限制双行高度避免压缩字号。
- **自定义时间与日期**：支持自定义格式、即时预览和恢复默认。也可继续使用预设日期格式。
- **硬件读数与位置**：每项读数可在同一选项中关闭或选择位置，支持状态栏左侧。支持自定义电池高温告警阈值和颜色。
- **全局开关完备覆盖**：模块总开关对状态栏、原生电池、图标抑制、通知中心天气与日期、时钟定制执行完备覆盖，关闭时即时无缝归还系统。
- **配置备份与独立恢复**：由专用控制器托管整份模块配置导出与导入，支持跨设备迁移并即时同步到宿主。
- **紧凑首页**：底部导航依次为「首页」「设置」「关于」。首页可并排选择圆环、胶囊和环外组件，并直接进入组件预览与排序。
- **设置分组**：「三合一」位于设置页最上方；状态栏设置第一行为「基础外观」与「通知/控制中心」，备份入口集中在「备份恢复」。关于页采用紧凑排版。
- **统一字号与紧凑子菜单**：首页、设置子菜单和关于页的主要文字统一为 14sp，说明文字为 11sp。子菜单扩大可用高度、收紧行距，预览区随内容滚动。应用语言支持简体中文、English 和跟随系统，选择后立即刷新当前页面。

## 安装与要求

### 要求

| 项目 | 说明 |
| :--- | :--- |
| **系统** | 荣耀 MagicOS |
| **Android** | 10 及以上（API 29+） |
| **框架** | 支持 libxposed **API 102** 的 LSPosed |
| **作用域** | 系统界面（`com.android.systemui`） |

### 安装步骤

1. 下载并安装最新版 `HonorDuoX-*.apk`。
2. 打开 LSPosed 管理器，启用 **HonorDuoX** 模块，并在作用域中勾选**系统界面**（`com.android.systemui`）。
3. 重启系统界面或重启手机即可生效。
