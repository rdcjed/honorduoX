# HonorDuoX 1.2.1

## 功能添加

- **状态栏图标整体缩放**。在「设置 → 基础外观」可将 Wi‑Fi、移动信号、电池等状态栏图标同时调至 50%～120%，默认 100%。
- **电池图标大小和竖向显示**。关闭三合一图标后，在「设置 → 电池电量」可将独立电池图标调至 50%～130%，并切换为竖向显示。
- **网速位置**。在「设置 → 硬件读数」可选择状态栏左顶、中部、右顶或还原系统位置。左顶与时钟左对齐，右顶与电池右对齐。

## 功能变更

- **状态栏左侧和右侧间距**。「设置 → 基础外观」可分别调整两侧间距，升级后原来的间距设定用于右侧。

下载 **HonorDuoX-1.2.1.apk** 覆盖安装，然后重启系统界面。
