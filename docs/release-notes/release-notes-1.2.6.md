# HonorDuoX 1.2.6

更新日期为 **2026-11-28**。

## 功能添加

- **下拉面板整体大小**：「设置 → 通知/控制中心」新增统一缩放，范围为 **50%～100%**。通知栏和控制中心的顶部、卡片、图标、文字与间距一起等比例变化，支持即时调整与备份恢复。

## 功能修复

- **下拉面板显示**：修复通知展开后卡片先放大、稍后才恢复的问题，以及收起、回弹时短暂跳回原尺寸的现象。缩小控制中心后，展开列表可以滚动到底部并完整显示最后一排卡片。
- **右侧图标间距**：修复「设置 → 基础外观」调整右侧间距后，系统界面重复布局、CPU 占用持续偏高的问题；正间距、负间距和恢复默认均可正常使用。
- **帧率读数**：修复快速切换帧率显示、熄屏或隐藏状态栏后，旧采样任务没有及时取消的问题，减少重复采样带来的额外开销。

## 功能变更

- **统一缩放入口**：通知栏和控制中心共用一个滑块，沿用之前的控制中心大小设置；100% 为系统大小，关闭模块总开关后恢复系统显示。
- **电池起始间距**：取消独立电池额外的固定 4dp 起始间距，右侧间距统一由「设置 → 基础外观」调整。
- **后台信号查询**：熄屏、状态栏不可见或关闭模块总开关时，跳过移动数据信号的定时查询，减少无效后台工作。

---

**安装**：下载 **HonorDuoX-1.2.6.apk** 覆盖安装，设置全部保留。安装后请重启系统界面或重启手机。
