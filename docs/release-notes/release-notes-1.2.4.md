# HonorDuoX 1.2.4

更新日期为 **2026-11-27**。

## 下拉通知与控制中心

- 设置入口由「控制中心」更名为「通知/控制中心」。
- 新增「控制中心整体大小」，支持 **50%～100%** 调整。顶部按钮、卡片、图标、文字和间距作为一个整体等比例缩放，保留系统原有布局。
- 新增独立的「通知卡片大小」，支持 **70%～120%** 调整，通知卡片、应用图标和文字一起缩放。
- 两项缩放设置均支持即时调整、备份恢复；100% 为系统大小，关闭模块时恢复系统显示。
- 修复控制中心缩小后，展开列表底部卡片被截断、无法完整显示的问题。
- 修复收起和回弹时卡片短暂恢复大尺寸、图标闪大的问题。

## 设置界面

- 首页、各模块子菜单和关于页的主要文字统一为 **14sp**，说明文字统一为 **11sp**，与设置模块的字号保持一致。
- 收紧列表行距和滑块区域间距，提高子菜单可用高度，让一屏显示更多设置项。
- 缩小子菜单预览区，并允许预览区随内容滚动，减少固定占用的空间。

## 语言切换

- 修复切换应用语言后界面没有反应、必须强制关闭再打开才能生效的问题。
- 简体中文、English 和跟随系统选择后立即刷新，保留当前页面。
- 修复从指定语言切回「跟随系统」时的语言恢复逻辑。

下载 **HonorDuoX-1.2.4.apk** 覆盖安装。由于本次包含系统界面 Hook 更新，安装后请重启系统界面或重启手机。
