## HonorDuoX 1.2.0

- **紧凑首页**：底部导航依次为「首页」「设置」「关于」。各页标题与刷新按钮对齐，首页缩小了开关行、卡片间距和预览，让首屏能显示更多内容。
- **合并风格**：「环外组件」与「圆环」「胶囊」并列，使用双排信号图标，可直接查看和排序环外组件。
- **自定义时间与日期**：支持自定义格式和即时预览，修复了恢复默认格式后输入框为空的问题。
- **硬件读数**：每项读数的开关和位置合在一起，新增「状态栏左侧」选项。
- **网络类型**：关闭三合一后，字号、字重和 5GA 中 A 的比例可以应用到独立标签与原信号样式堆叠。

下载 **HonorDuoX-1.2.0.apk** 覆盖安装，更新后重启系统界面使模块生效。
