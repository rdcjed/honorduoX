## HonorDuoX 1.1.0

- **双卡信号**：可选「信号堆叠（原信号样式）」，双卡上下排列，支持 4 柱或 5 柱。当前流量卡的信号显示系统原生流量箭头。
- **Wi‑Fi 图标**：「无线网络」中可选圆润弧线、圆润回环、分层扇形和原样。自定义样式可切换三层或四层，调整尺寸和粗细。颜色支持跟随系统、深蓝、柔和绿和粉色。
- **网速显示**：「硬件读数」新增 60%–100% 的网速字号调节。网速由系统原生控件测速、刷新和显示，颜色跟随系统；可调字号后数字和单位仍留有行距，无 Wi‑Fi 图标时网速和 5G 之间保留空隙。
- **状态栏图标**：「基础外观」新增图标间距滑杆。电池、Wi‑Fi、移动信号分别提供显示开关。

从本页下载 **HonorDuoX-1.1.0.apk** 安装，更新后重启系统界面即可生效。
