# HonorDuoX 1.2.2

更新日期为 **2026-11-27**。本次说明汇总当天 1.2.1 与 1.2.2 的调整。

## 功能添加

- **状态栏图标整体缩放**。在「设置 → 基础外观」可将 Wi-Fi、移动信号、电池等图标同时调至 50%～120%，默认 100%。
- **状态栏左右间距**。在「设置 → 基础外观」可分别调整左侧和右侧图标间距，原来的间距设定用于右侧。
- **状态栏高度**。在「设置 → 基础外观」可在系统高度基础上调整 −8 到 +16 dp，0 dp 跟随系统。降低时保留摄像头开孔和图标所需空间。
- **网速位置**。在「设置 → 硬件读数」可选择状态栏左顶、中部、右顶或还原系统位置。左顶与时钟左对齐，右顶与电池右对齐，并调整了上下间距。
- **电池图标大小和竖向显示**。关闭三合一图标后，在「设置 → 电池电量」可将独立电池图标调至 50%～130%，并切换为竖向显示。竖向样式进一步缩小并调整了对齐。

## 功能修复

- **Wi-Fi 绿色**。在「设置 → 无线网络」选择绿色后，与电池充电色同步。独立图标使用核对后的原生充电绿 #35C759，三合一启用状态颜色时跟随当前背景对应的充电颜色。

## 功能变更

- **设置分组**。「三合一」移至设置页最上方，圆环和胶囊参数集中在「合并风格与尺寸」。状态栏设置第一行为「基础外观」与「控制中心」，其余模块按顺序排列，并适当加高卡片。
- **控制中心**。原「通知面板与控制中心」入口改名为「控制中心」，与状态栏其他设置放在一起。
- **备份恢复**。导入和导出备份集中在「设置 → 备份恢复」，环外组件的预览和排序保留在首页。
- **关于**。压缩激活状态、设备信息、操作列表和详情页标题区域，让首屏显示更多内容。
- **波纹样式**。取消试用中的 Wi-Fi、移动信号和电池波纹套装，使用现有图标样式。
