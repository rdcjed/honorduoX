# HonorDuoX 1.2.2

## 功能添加

- **状态栏高度**。在「设置 → 基础外观」可在系统高度基础上调整 −8 到 +16 dp，0 dp 跟随系统。降低时保留摄像头开孔和图标所需空间。

## 功能修复

- **Wi-Fi 绿色**。在「设置 → 无线网络」选择绿色后，与电池充电色同步；三合一启用状态颜色时，跟随当前浅色或深色背景的充电颜色。

## 功能变更

- **设置分组**。「三合一」移至设置页最上方，圆环和胶囊参数集中在「合并风格与尺寸」。状态栏设置第一行为「基础外观」与「控制中心」，其余模块按顺序排列，并适当加高卡片。
- **控制中心**。原「通知面板与控制中心」入口改名为「控制中心」，与状态栏其他设置放在一起。
- **备份恢复**。导入和导出备份集中在「设置 → 备份恢复」，环外组件的预览和排序保留在首页。
- **关于**。压缩激活状态、设备信息、操作列表和详情页标题区域，让首屏显示更多内容。

下载 **HonorDuoX-1.2.2.apk** 覆盖安装，然后重启系统界面。
